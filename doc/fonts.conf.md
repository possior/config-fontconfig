# Fontconfig説明書

以下のXML文は、XML 1.0の使用を宣言する。

```XML
<?xml version="1.0"?>
```

以下のXML文は、`fontconfig`という名称で定義されている文法の使用を宣言する。

```XML
<!DOCTYPE fontconfig SYSTEM "urn:fontconfig:fonts.dtd">
```
